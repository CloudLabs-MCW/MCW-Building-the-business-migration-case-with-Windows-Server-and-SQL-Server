## Question
Under the migration strategies described in the business case, what happened to the server you Azure Arc-enabled?

## Options
Option 1 : It was rehosted.
Option 2 : It was replatformed.
Option 3 : It was retained.
Option 4 : It was retired.

## Answers
Option 3 : 5

## Correct Answer Feedback
Correct! The server stays exactly where it is. Azure Arc brings Azure management to it rather than moving it to Azure.

## Incorrect Answer Feedback
That's not correct. Ask yourself whether that server actually moved anywhere during the lab, and review the migration strategy table in the Building the Business Case section.
