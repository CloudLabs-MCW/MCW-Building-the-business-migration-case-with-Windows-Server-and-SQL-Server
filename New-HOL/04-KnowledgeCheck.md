# Exercise 04: Knowledge Check

### Estimated Duration: 30 Minutes

## 📘 Lab Scenario

You have migrated the Tailspin Toys database to Azure SQL Managed Instance, created the application server that will host the migrated web application, and brought the remaining on-premises server under Azure management with Azure Arc. This knowledge check lets you reflect on the decisions you made and the steps you carried out.

## 📋 Overview

There are fifteen questions covering the migration decisions you made, the steps you carried out, and the reasoning behind them. Each question has four options and allows two attempts. If your first answer is wrong, you'll get a hint and a chance to try again.

Answer the questions in order. Everything you need is in the exercises you have already completed.

## 🎯 Objectives

In this exercise, you will complete the following tasks:

- **Task 1:** Migration strategy and target selection
- **Task 2:** The migration process
- **Task 3:** Verifying the migrated database
- **Task 4:** Networking and secure access
- **Task 5:** Azure Arc
